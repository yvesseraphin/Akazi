# Akazi Germany

B2B platform connecting German employers with vetted, bilingual Rwandan apprentices for dual vocational training (Ausbildung) — with certified B2 German, visa processing support, and continuous mentorship.

## Tech Stack

- **Framework**: Next.js 15 (App Router, React 19)
- **Styling**: Vanilla CSS Modules & Tailwind CSS
- **Icons**: Lucide React
- **Image Optimization**: Sharp

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
